## IT桔子上线后复核

- 端点 `https://mcp.itjuzi.com/mcp` 仍可协商 MCP `2025-06-18`，服务版本仍为 `1.27.1`。
- `tools/list` 仍返回 21 个工具；这些工具仍未提供 MCP annotations，所以卡片应继续标记 `partial`，不能升级为完整只读验收。
- 无 API Key 调用 `get_lookup_options` 返回工具错误，说明业务访问仍受鉴权保护；未保存原始响应。
- [公开价格权益](https://github.com/lgyers/itjuzi-mcp/blob/main/docs/pricing.md)仍写明：团队问答适合人在 MCP 客户端投研问答，不支持批量导出、系统入库或平台分发。
- 结论：保持现有卡片和 `partial` 状态；若服务方提供专用测试 Key，再补一条范围受限的只读业务验收，不得记录 Key 或原始业务数据。

## 可复现验收

以下命令在 Registry 提交 `8f1f3fa` 上运行，不写入原始响应：

```bash
node scripts/run-runtime-acceptance.mjs \
  --url https://hkex-listco-updates.ascent-partners.com/api/mcp \
  --tool get_server_info \
  --reviewer dsh-p3-review

node scripts/run-runtime-acceptance.mjs \
  --url https://uis.sidneybissoli.com/mcp \
  --tool uis_list_geo_units \
  --reviewer dsh-p3-review

node scripts/run-runtime-acceptance.mjs \
  --url https://mcp.shumi.ai/mcp \
  --tool get_market_health \
  --reviewer dsh-p3-review
```

前两条应为元数据级 `pass`，但不证明公告或统计值的业务数据质量；第三条在没有授权测试 Key 时应为 `tool-error`。三个候选都保持 `DEFERRED`。运行前仍须检查目标 URL 与官方仓库现状，不得把历史结果当作永久 SLA。
